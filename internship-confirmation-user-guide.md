# Internship Confirmation — Step by Step Guide

This page is where colleges record which students did an internship, and where the State
office can view/download that data for all colleges. Simple steps below — no technical
knowledge needed.

---

## For Principals (College)

### 1. Login
1. Open **https://placeintern.com** in your browser.
2. Enter your Principal **email/username** and **password**.
3. Click **Login**.

### 2. Go to the Internship Confirmation page
1. On the left-side menu, look for **"Internship Confirmation"**.
2. Click on it. This opens your college's internship confirmation page.

### 3. Choose how you want to add data
You'll see two tabs at the top: **"Manage Reports"** and **"Bulk Upload"**.

#### Option A — Add one student at a time (Manage Reports tab)
1. Click the **"Add Report"** button (top right).
2. Search and select the student.
3. Fill in the internship details (company name, whether stipend was given, work location,
   faculty mentor, etc.). Only Company Name is compulsory — fill the rest as available.
4. Click **Save**.
5. Repeat for each student. You can also **Edit** or **Delete** any entry later from the same
   list using the "⋮" menu next to each row.

#### Option B — Add many students at once (Bulk Upload tab)
This is faster if you have many students to add.

1. Click the **"Bulk Upload"** tab.
2. Click **"Download Template"**. This downloads an Excel file that already has your
   college's student list filled in (name, roll number, branch, etc.).
3. Open the downloaded Excel file and fill in the internship details for each student in the
   empty columns (Company Name, Mode of Internship, Stipend, etc.).
   - **Do not touch or delete the hidden "Student ID" column** — it's used to match the row
     back to the right student.
   - Leave a row completely blank if that student has nothing to report yet.
4. Save the Excel file on your computer.
5. Go back to the website, and either drag-and-drop the file into the upload box, or click it
   to browse and select your saved file.
6. The page will show you a **preview table** of every row — which ones are valid (green) and
   which have problems (red, with the reason explained, e.g. "Company name is required").
7. Fix any errors in your Excel file and re-upload if needed, or just proceed — rows with
   errors are simply skipped, valid rows still go through.
8. Click **"Upload Valid Record(s)"**.
9. You'll see a final summary: how many were **Total / Success / Failed**, with details for
   each. If something failed, the reason is shown next to it.

That's it — the records are now saved for your college.

## For State Directorate (State Office)

### 1. Login
1. Open **https://placeintern.com** in your browser.
2. Enter your State Directorate **email/username** and **password**.
3. Click **Login**.

### 2. Go to the Internship Confirmation page
1. On the left-side menu, click **"Internship Confirmation"**.
2. This shows a read-only list of internship records from **all colleges** (you cannot
   add/edit/delete here — only colleges do that).

### 3. Filter (optional)
Use the filters at the top to narrow the list down — for example, by **district** or by a
specific **college/institution**.

### 4. Export for government submission
1. Click the **"Export"** button.
2. An Excel file will download in the exact government report format, with all the columns
   already filled in from what colleges have submitted.
3. Use this file for your TPO/DTE submission.

---

## Quick Notes
- Principals can only see and edit their own college's students — never any other college's.
- State Directorate can only **view and export** — they cannot add, edit, or delete records.
- This data is separate from a student's main internship record in the system — it's only
  used for the periodic government confirmation/report.
